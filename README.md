# 一閃 · The Last Flash

魂系時機遊戲。年輕殺手浩然，後巷一拳開始，一路老去。

開 `index.html` 就可以玩（唔使 build）。

## 玩法

- 拳頭、刀接近喻陣，時間會慢。槍關係開槍之後子彈飛近。
- 畫面上掻會隨機出現。作出適當反應。再等會有更短窗口。
- 失手一次即死。
- 過關之後有「下一關」掻，窗口好長。唔撲就唔解鎖下一關。

## 關卡

1. 後巷（拳頭）— 惡徒調戲學生妹
2. 入行（刀 · 三人）
3. 任務（槍 · 殺一個殺手）
4. 敵營（槍 · 五人）
5. 中年（槍）
6. 刀再一次（刀 · 三人）
7. 最後一拳（拳頭）

第一關過關之後會有好短嘅「睇吓條女有冊事」。撲到入隱藏關。真正答案「我叫浩然！」先解鎖隱藏關同 If「識到學生女」。

## 存檔

進度嗚瀏覽器 `localStorage`（`yat-sim-save-v2`）。
